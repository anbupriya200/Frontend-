Full Stack

Full stack refers to the entire depth of a computer system or web application, consisting of both the front end (client-side) and back end (server-side), including databases and software logic.

HTML

HTML stands for HyperText Markup Language, and it is the standard code used to structure a web page and its content.

CSS

CSS stands for Cascading Style Sheets. It is the standard code language used to design, style, and layout the visual appearance of web pages
