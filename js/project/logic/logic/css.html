Topic 01

CSS Introduction

Definition
CSS (Cascading Style Sheets) describes how HTML elements are styled and presented visually across screen sizes and device types.
Detailed Explanation

CSS works by matching selectors to HTML elements and applying key-value styling rules (e.g. color, font-size, background). The term "Cascading" means rules flow downwards based on specificity priority and document order.

Topic 02

Inline CSS

Definition
Inline CSS applies styling directly to a single HTML tag via the style="..." attribute.
Technical Analysis & Specificity

Inline CSS carries the highest specificity score (1000), overriding internal and external CSS rules regardless of stylesheet order.

Topic 04

External CSS Stylesheets

Definition
External CSS links separate .css stylesheet files to HTML pages via <link rel="stylesheet" href="style.css">.
Industry Standard Best Practices

External CSS is the industry gold standard. Browsers cache .css files locally after the first download, drastically accelerating subsequent page load speeds across multi-page web applications.

Topic 05

CSS Selectors & Specificity

Definition
CSS Selectors target HTML elements via tag names (h1), classes (.title), element IDs (#main), attributes ([type="text"]), or combinators (div > p).
Specificity Ranking Breakdown

1. !important: Overrides all specificity rules.
2. Inline Style (1000): style="..."
3. ID Selector (0100): #header
4. Class & Attribute Selector (0010): .btn, [type="submit"], :hover
5. Element Tag Selector (0001): div, p, h1

Topic 07

CSS Backgrounds & Gradients

Definition
CSS background properties control element colors, background images, positioning, repeat options, and vibrant linear/radial gradients.
Detailed Properties Breakdown

• background-color: Solid background color.
• background-image: linear-gradient(135deg, #3b82f6, #8b5cf6): Vibrant color transitions.
• background-size: cover: Scales background image to fill container completely.
• background-position: center: Centers background image horizontally and vertically.

Fonts & Typography

Definition
CSS typography rules control font family stacks, font sizes, line heights, letter spacing, and text alignments.
Typography Rules Breakdown

• font-family: 'Inter', sans-serif: Primary font family stack with fallback options.
• font-size: 1rem / 16px: Text font sizing (use relative `rem` units for responsiveness).
• line-height: 1.6: Vertical line height spacing for optimal reading comfort.
• letter-spacing: 0.05em: Character tracking spacing.

Topic 09

CSS Box Model Sizing

Definition
The Box Model governs how every HTML element is calculated as a rectangular box comprising Content, Padding, Border, and Margin.
Box Sizing Mode Comparison

• box-sizing: content-box (Default): Total Width = Content Width + Padding + Border.
• box-sizing: border-box (Modern Standard): Total Width = Specified Width (Padding and Border are included inside the specified width).

Try It Live Sandbox
Box Sizing SandboxLive Box
Important Points
  • Always set *, *::before, *::after { box-sizing: border-box; } in your CSS reset baseline.
Common Mistakes
  • Assuming `width: 100%` won't overflow containers when adding padding under `content-box`.
Topic 10

CSS Margin & Collapse

Definition
Margin creates transparent external spacing outside an element's border, pushing neighboring elements away.
Detailed Features & Margin Collapse

• margin: auto: Horizontally centers block elements with a defined width.
• Margin Collapse: Top and bottom vertical margins of adjacent block elements collapse into a single margin equal to the largest individual margin value.

Try It Live Sandbox

Important Points
  • margin: 0 auto requires a fixed or max-width declaration to center block containers.
Common Mistakes
  • Expecting vertical `margin: auto` to center elements without using Flexbox or Grid.
Topic 11

CSS Padding

Definition
Padding creates internal breathing space inside an element's border line around its core content.
Shorthand Property Syntax

• padding: 20px; (All 4 sides)
• padding: 10px 20px; (Top/Bottom Left/Right)
• padding: 10px 15px 20px 25px; (Top Right Bottom Left - Clockwise order)

Borders & Border Radius

Definition
The border property draws outer stroke lines around elements, while border-radius rounds corner edges.
Border Styles & Radius Breakdown

• border: 2px solid #3b82f6: Width, style (solid, dashed, dotted), and stroke color.
• border-radius: 8px / 50% / 9999px: Softens sharp corners (use 50% for circles; 9999px for pill buttons).

Topic 13

CSS Display Property

Definition
The display property determines the layout rendering behavior of an element and its child nodes in the DOM tree.
Core Display Values Overview

• display: block: Takes full container width, starts on a new line.
• display: inline: Respects content width only; ignores width/height declarations.
• display: inline-block: Flows inline with text while respecting width and height bounds.
• display: flex: Enables 1D flexbox container layout.
• display: grid: Enables 2D grid container layout.
• display: none: Completely removes element from DOM rendering tree.

Try It Live Sandbox
Display SandboxLive Output
Important Points
  • display: none removes elements from visual layout AND screen reader accessibility trees.
Common Mistakes
  • Confusing `display: none` with `visibility: hidden` (visibility reserves layout whitespace).
Topic 14

CSS Position Property

Definition
The position property manipulates element positioning coordinates (top, right, bottom, left, z-index).
Position Values Breakdown

• static (Default): Standard normal document flow.
• relative: Positioned relative to its normal position without affecting sibling flow.
• absolute: Positioned relative to its nearest non-static positioned ancestor parent.
• fixed: Positioned relative to the browser viewport window; stays fixed on scroll.
• sticky: Toggles between relative and fixed based on scroll position.

Try It Live Sandbox
Positioning SandboxLive Output
Important Points
  • Pair position: absolute on children with position: relative on the parent wrapper container.
Common Mistakes
  • Using `position: absolute` without setting `position: relative` on the parent, causing elements to fly up to the body element.
Topic 15

Flexbox Layout Engine

Definition
Flexible Box Layout (Flexbox) provides a 1-dimensional arrangement model for distributing space and aligning items along a main axis or cross axis.
Essential Flexbox Properties

• flex-direction: row / column: Sets main axis direction.
• justify-content: flex-start / center / space-between / space-around: Aligns items along main axis.
• align-items: stretch / center / flex-start / flex-end: Aligns items along cross axis.
• gap: 16px: Sets spacing gap between flex child items.

Common Mistakes

Topic 16

CSS Grid Layout

Definition
CSS Grid is a 2-dimensional layout model for handling complex page layouts with customizable rows and columns simultaneously.
Key Grid Properties

• grid-template-columns: repeat(3, 1fr) / repeat(auto-fit, minmax(250px, 1fr)): Defines responsive column structures.
• gap: 20px: Specifies row and column gap dimensions.
• grid-column: span 2: Spans a child cell across 2 grid columns.

Try It Live Grid Playground
Interactive Grid EditorLive Result
Important Points
  • grid-template-columns: repeat(auto-fit, minmax(280px, 1fr)) creates responsive layout grids without media queries.
Common Mistakes
  • Hardcoding pixel column widths on grids, causing horizontal scrolling overflow on small mobile screens.
Topic 17

CSS Pseudo-Classes

Definition
Pseudo-classes (prefixed with a single colon :) target elements based on user interaction states or DOM structural positions.
Common Pseudo-Classes Overview

• :hover: Styles element when user hovers pointer over it.
• :focus: Styles input element when focused via keyboard or click.
• :nth-child(even / 2n): Selects elements based on their numerical index position in parent container.
• :not(.disabled): Negation pseudo-class selector.

Important Points
  • Always provide clear visible :focus-visible styles for keyboard accessibility users.
Common Mistakes
  • Removing outline focus indicators (`outline: none`) without supplying an alternative `:focus` style.
Topic 18

CSS Pseudo-Elements

Definition
Pseudo-elements (prefixed with a double colon ::) style specific sub-parts of an element or inject virtual cosmetic markup.
Key Pseudo-Elements Breakdown

• ::before & ::after: Injects decorative content before or after element content (requires content: '').
• ::first-letter: Styles the first letter of text blocks (drop caps).
• ::placeholder: Styles input placeholder text.

Topic 19

CSS Media Queries

Definition
Media queries apply conditional CSS rule blocks based on target device screen width, orientation, resolution, or dark mode preferences.
Syntax & Mobile-First Breakpoints

• Mobile-First standard breakpoint rule:
@media (min-width: 768px) { ... } (Triggers on screens 768px and wider).
• Dark Mode Preference Rule:
@media (prefers-color-scheme: dark) { ... }

Topic 20

Fluid Responsive Web Design

Definition
Responsive Web Design (RWD) ensures webpages dynamically adapt visual layouts, text scaling, and media fluidly across smartphones, tablets, laptops, and 4K displays.
Pillars of Responsive Design

1. Fluid Grids: Use relative percentage units (%, vw, fr) instead of fixed pixels.
2. Flexible Media: Ensure images scale using max-width: 100%; height: auto;.
3. Media Queries: Reorganize multi-column layouts into single-column vertical stacks on small viewports.

Common Mistakes
  • Hardcoding fixed width values like `width: 1200px` without supplying responsive `max-width: 100%`.

💡 12 Essential CSS Interview Questions

Key layout and specificity questions asked in frontend interviews.

In border-box, padding and border are included inside the specified width. In content-box, padding and border add to the specified width.
Flexbox is 1-dimensional (rows or columns). Grid is 2-dimensional (rows and columns simultaneously).
Inline (1000) > ID (100) > Class/Pseudo-class (10) > Element tag (1).
