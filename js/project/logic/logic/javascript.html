Topic 01

JavaScript Introduction

Definition
JavaScript is a high-level, lightweight, just-in-time compiled, object-oriented programming language that powers dynamic interactivity on the Web.
Detailed Explanation & Engine Mechanics

JavaScript runs inside browser engines (e.g. V8 in Chrome, SpiderMonkey in Firefox). It is single-threaded and relies on an Event Loop architecture to handle asynchronous tasks like API fetches and timer callbacks without blocking UI rendering.

Important Points
  • JavaScript is dynamically typed (variables can change value data types at runtime).
Common Mistakes
  • Confusing JavaScript with Java (they are completely different languages).
Topic 02

JavaScript Variables

Definition
Variables are named containers in memory used to store references to data values (`let`, `const`, `var`).
Declaration Keywords Comparison

• let: Block-scoped, re-assignable value.
• const: Block-scoped, non-reassignable constant reference.
• var: Function-scoped legacy variable subject to hoisting.

Important Points
  • Default to using const unless you explicitly plan to reassign a variable value.
Common Mistakes
  • Using undeclared variables without `let` or `const` (creates accidental global variables).
Topic 03

let Statement

Definition
The let keyword declares a block-scoped local variable, optionally initializing it to a value.
Temporal Dead Zone (TDZ)

Variables declared with let are hoisted to the top of their block scope but cannot be accessed until initialization line executes (accessing prior triggers a `ReferenceError`).

Important Points
  • let variables cannot be redeclared within the exact same block scope.
Common Mistakes
  • Attempting to read a `let` variable before its declaration line in code.
Topic 04

const Statement

Definition
The const keyword declares read-only block-scoped constants whose variable identifiers cannot be reassigned.
Mutation vs Reassignment

const prevents reassigning the variable identifier to a new value (e.g. PI = 3.14 works; PI = 4 errors). However, properties inside constant Objects or Arrays CAN still be mutated!

Important Points
  • Must be initialized with a value at the exact line of declaration.
Common Mistakes
  • Attempting to reassign a `const` variable (causes `TypeError: Assignment to constant variable`).
Topic 05

var Statement

Definition
var is the legacy pre-ES6 function-scoped variable declaration subject to hoisting.
Why var is Avoided in Modern Code

var ignores block scope boundaries (if/for blocks), leaking variables into outer scopes. It is hoisted to top of function with `undefined` initial values.

Important Points
  • Avoid using var in modern ES6+ codebases; use const and let instead.
Common Mistakes
  • Accidental variable leakage out of `for` loops due to `var` function scoping.
Topic 06

JavaScript Data Types

Definition
JavaScript data types are categorized into 7 Primitives (immutable) and 1 Reference Object type.
Primitives vs Reference Types

• Primitives: String, Number, Boolean, Undefined, Null, BigInt, Symbol (Stored by value).
• Reference Types: Objects, Arrays, Functions (Stored by memory address reference).

Important Points
  • Use typeof variable to inspect primitive data types at runtime.
Common Mistakes
  • Assuming `typeof null` returns "null" (it legacy returns "object" in JS).
Topic 07

JavaScript Operators

Definition
Operators perform mathematical, logical, and assignment operations on operands.
Operator Categories

Includes Arithmetic (+, -), Assignment (=, +=), Comparison (===), Logical (&&, ||), and Ternary (condition ? a : b).

Topic 08

Arithmetic Operators

Definition
Arithmetic operators perform standard mathematical calculations on numeric operands.
Operators Breakdown

• Addition (+), Subtraction (-), Multiplication (*), Division (/)
• Modulus (%): Returns remainder after division.
• Exponentiation (**): Powers calculation (2 ** 3 = 8).

Topic 09

Comparison Operators

Definition
Comparison operators test equality and ordinal relationships between values, returning boolean true or false.
Strict Equality vs Loose Equality

• === (Strict Equal): Checks both Value AND Data Type without type coercion.
• == (Loose Equal): Performs automatic type coercion before comparing (avoid!).

Topic 10

Logical Operators

Definition
Logical operators (&& AND, || OR, ! NOT) combine multiple boolean conditions.
Short-Circuit Evaluation

• &&: Short-circuits and returns first falsy value.
• ||: Short-circuits and returns first truthy value.

Topic 11

if Statement

Definition
The if statement executes a code block only if its condition expression evaluates to truthy.
Topic 12

if...else Statement

Definition
Executes the primary block if condition is true, or alternative else block if false.
Topic 13

else if Statement

Definition
Chains multiple conditional evaluations sequentially until a truthy condition matches.
Topic 14

for Loop

Definition
Repeats execution loop for a specified iteration count: for (let i = 0; i < N; i++).
Topic 15

while Loop

Definition
Executes a code loop repeatedly as long as condition remains truthy.
Topic 16

Functions & Arrow Functions

Definition
Functions are reusable subroutines accepting parameter inputs and returning computational output values.
Arrow Functions ES6 Syntax

const add = (a, b) => a + b; provides concise syntax and lexically binds the this keyword from outer scope.

Topic 17

JavaScript Arrays

Definition
Arrays are zero-indexed ordered list collections storing multiple data values inside single variable references.
Topic 18

Strings & Template Literals

Definition
Strings store text sequences. Template literals (`Hello ${name}`) support string interpolation and multi-line strings.
Topic 19

JavaScript Objects

Definition
Objects store keyed collections of properties and methods: { name: "John", age: 25 }.
Topic 20

Array Higher-Order Methods

Definition
Methods like .map(), .filter(), .reduce(), .forEach() transform and iterate array data functionally.
Topic 21

String Utility Methods

Definition
Utility methods like .includes(), .slice(), .split(), .toLowerCase() manipulate string text.
Topic 22

DOM Architecture Intro

Definition
The Document Object Model (DOM) is an object API tree interface allowing JavaScript to dynamically access, modify, and style HTML tags.
Topic 23

DOM Element Selectors

Definition
Methods like document.getElementById(), document.querySelector(), and document.querySelectorAll() locate DOM nodes.
Topic 24

DOM Event Handling

Definition
element.addEventListener('click', handler) listens for user interactions (clicks, keypresses, form submits).
Topic 25

JavaScript Form Validation

Definition
Validates input field length, regex formats, and password match criteria before permitting form submission.

4. Find the Sum of Digits

Question: Calculate the sum of all individual digits in a given number (e.g. 12345).
Step-by-Step Logic Breakdown:
  1. Input value = 12345.
  2. Convert number to string: String(12345) → "12345".
  3. Loop through every digit character in sequence.
  4. Convert each character back to number using Number(char).
  5. Sum digits: 5 + 4 + 3 + 2 + 1 = 15.
Original Source Code
let value = 12345;
let sum = 0;

let numberString = String(value);

for (let i = 0; i < numberString.length; i++) {
  sum = sum + Number(numberString[i]);
}

console.log(sum);

💡 15 Essential JavaScript Interview Questions

Core concepts asked in frontend engineering interviews.

== performs implicit type conversion before comparison. === evaluates strict equality comparing both value AND data type without coercion.
A closure gives an inner function access to an outer function's scope variables even after the outer function has executed and returned.
Bubbling travels upwards from target element to parent document nodes. Capturing travels downwards from window root to the target element.
The Event Loop continuously checks if the Call Stack is empty and moves callbacks from the Microtask/Task Queue into the Call Stack for execution.
var is function-scoped and hoisted. let and const are block-scoped and exist in the Temporal Dead Zone until declared. const prevents variable identifier reassignment.
