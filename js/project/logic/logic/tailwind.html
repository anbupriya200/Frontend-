Topic 01

Tailwind CSS Introduction

Definition
Tailwind CSS is a utility-first CSS framework providing low-level atomic classes to compose custom UI designs directly inside HTML markup.
Detailed Architecture & JIT Compiler

Unlike component-based frameworks (like Bootstrap), Tailwind provides atomic utility primitives. Its Just-In-Time (JIT) compiler scans your HTML files at build time and generates only the exact CSS classes used, resulting in ultra-compact production CSS bundles.

  • No need to write custom CSS class names or invent naming conventions like BEM.
Common Mistakes
  • Thinking utility classes make HTML bloated; JIT build tools produce minimal production bundles.
Topic 02

Installation & Play CDN

Definition
Tailwind can be included via the Play CDN script for rapid prototyping or installed via PostCSS CLI/Vite for production build pipelines.
CDN vs PostCSS Production Setup

• Play CDN: Add <script src="https://cdn.tailwindcss.com"></script> to document <head> (great for learning and sandboxes).
• PostCSS CLI / Vite: Installs `tailwindcss` via npm and generates purged production CSS.

Important Points
  • Do not use the Play CDN script in production environments.
Common Mistakes
  • Forgetting to configure `content` paths in `tailwind.config.js` when building for production.
Topic 03

Utility Classes Concept

Definition
Utility classes are single-purpose helper classes (e.g. p-4, text-center, font-bold) combined to build complex UI widgets.

Topic 06

Spacing Utilities (Padding & Margin)

Definition
Spacing uses a 4-px scale (e.g. p-4 = 16px, mt-2 = 8px, mx-auto = horizontal auto center).
Topic 07

Width & Height Sizing

Backgrounds & Gradients

Borders & Divide Utilities

Flexbox in Tailwind

Class Breakdown

• flex → display: flex;
• justify-between → justify-content: space-between;
• items-center → align-items: center;
• gap-4 → gap: 1rem; (16px)
